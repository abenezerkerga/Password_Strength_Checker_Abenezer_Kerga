# Password Strength Checker

A beginner-friendly Python project that evaluates password strength using basic rules and provides suggestions for improvement.

## Features
- Checks password length
- Checks for uppercase and lowercase letters
- Checks for numbers and symbols
- Identifies a small list of common weak passwords
- Provides suggestions for improvement
- Allows users to check multiple passwords in one session

## Technologies
- Python
- `string` module
- `getpass` module

## How to Run

Run the script using Python:

```bash
python password_strength_checker.py
```

**Note:** This is an educational project. It uses simple checks and a small list of common passwords; it is not a complete password-security assessment tool.
